# The working method — intent, clusters, on-page, links

`knowledge.md` and `aeo.md` hold facts with sources. This file holds the
*method*: the order of work, and the parts where no source exists and it is
judgement. Labels are honest:

- **[P-verified]** — Google's own documentation, read during a refresh.
- **[S]** — secondary study or trade source.
- **[judgement]** — standard practice with no citation behind it. Treat as a sensible default, not a fact. Don't present these to the user as proven.

Last refresh: **2026-10-03**.

---

## 1. Match intent before writing

Four intents: **informational** (learn), **commercial** (compare), **transactional** (buy/act), **navigational** (a specific site). **[judgement]** — a widely used taxonomy; Google doesn't publish it as a ranking input.

- **How to check:** search the keyword and look at what the top 10 actually are. If they're all calculators, a long essay won't rank, however good it is. **[judgement]**
- **Our pipeline already does this**: every idea carries an `intent` field, and competition is judged from who currently ranks (`research()` in `agent.ts`).
- For PFT, almost everything will be informational. Google's data: **99.9% of AI-Overview keywords are informational** **[S]** (Ahrefs, 2026-01), so informational is also where AI answers live.

## 2. Pick keywords by four tests

Demand, fit, intent, difficulty. **[judgement]** as a framework; each input can be grounded:

- **Demand** — Google autocomplete gives real queries, ordered roughly by popularity. Free, no API. Exact volumes need a paid tool (Keyword Planner, DataForSEO); we don't have one, and the agent labels its demand as an estimate.
- **Fit** — does the reader have any reason to care about *our* site answering this? For PFT: money management by salaried Indians. Anything else is traffic we can't use.
- **Difficulty** — read the SERP: regulators, banks and big publishers with thorough pages = hard; forums, Quora, thin or outdated pages = winnable. **[judgement]**
- **Where to find ideas:** Search Console queries once we have them (our own data beats any tool), "People also ask", autocomplete, and gaps in what ranks. **[judgement]**

## 3. Build clusters, not one-offs

One pillar post on the head term, plus supporting posts covering each subtopic, all interlinked.

- **The grounded reason:** Google confirms AI Mode/AI Overviews use **query fan-out** — "a set of concurrent, related queries generated by the model" — so a page can be cited for a question nobody typed. Covering a topic's subtopics is how you show up in that fan-out. **[P-verified]** https://developers.google.com/search/docs/fundamentals/ai-optimization-guide
- **[S]** supporting signal: pages ranking for a query's fan-out sub-queries were 161% more likely to be cited (single study, not replicated).
- "Topical authority" as a named ranking system is **[judgement]** — Google has never confirmed one. The fan-out mechanism is the part that's documented.
- **Implemented:** tick "Build a topic cluster" when researching. The pillar comes back first, supporting posts link back to it, the pillar links out to each of them, and the scheduler puts the pillar live first.

## 4. On-page basics

All of these are enforced in `seoReport()` or the prompts — the list is here so we know *why* each one exists:

| Item | Rule | Basis |
|---|---|---|
| Title | Contains the keyword, ≤60 characters, worth clicking | **[judgement]**; 60 chars is a display limit, not a ranking rule |
| Meta description | 120–160 chars, gives a reason to click | **[judgement]**; Google often rewrites it, and it isn't a ranking factor |
| URL slug | Short, descriptive, contains the keyword | **[judgement]** |
| Headings | Clear H2/H3 sections | **[P-verified]** — Google's gen-AI guide asks for "clear headers and sections" |
| Internal links | Connect cluster members; help discovery | **[P-verified]** — Google lists internal linking under AI-feature best practice |
| Images | Descriptive filename and alt text | **[judgement]** for filenames; alt text is an accessibility requirement regardless |
| Keyword density | Upper bound only — stuffing is spam, no minimum helps | **[P-verified]** spam policy + **[P]** research (stuffing null-to-negative) |
| Freshness | Update genuinely, then change the date | **[S]** 75% of AI-cited pages updated within a year; **[P-verified]** faking dates is a quality red flag |

## 5. Earn links

Links are the biggest gap for a new domain. In rough order of what works for a one-person site **[judgement]**, with the one measured note flagged:

1. **Be the source.** Original data from Personal FT, or a free tool (calculator, template) people cite for years. The `tools` subdomain exists for exactly this.
2. **Your own audience.** YouTube descriptions, newsletter, socials. Not "link building" — just distribution. Worth noting: **YouTube mentions had the highest correlation (0.74) with AI-Overview brand visibility** in the largest dataset available **[S]**, higher than backlinks (0.22). Correlation only.
3. **Journalist requests.** Reply to finance queries on Source of Sources (the HARO successor), Featured, Qwoted. You're a real founder with real expertise, which is what they want. **[judgement]**
4. **Communities, helpfully.** r/IndiaInvestments, Quora. Answer properly; link only when it genuinely helps. Drive-by links get removed and earn nothing.
5. **Don't buy links.** Link spam is a named Google spam policy. **[P-verified]**

Google's caution applies here: chasing **inauthentic** mentions "isn't as helpful as it might seem". **[P-verified]**

## 6. Technical hygiene

- **Done:** sitemaps and robots.txt on all four sites; canonical host fixed to www; posts render server-side; scheduled posts hidden by RLS until their time.
- **Not done, worth doing once there are ~20 posts:** a crawl to find broken links, redirect chains and missing metadata. Screaming Frog's free tier (500 URLs) covers us for years. **[judgement]**
- **Per-post checks already automated:** dead external links are stripped, slugs are unique, images have alt text.
- **Not applicable:** Google Business Profile — no physical location.
- **Worth setting up:** Bing Webmaster Tools, for the only report that shows which queries triggered an AI citation. **[P]**

## 7. Measure, then improve what's close

1. Search Console → queries ranking 8–20. Those are the cheap wins: answer the query more directly, then update.
2. Generative AI performance report for AI impressions (impressions only). **[P-verified]**
3. GA4's "AI Assistant" channel for ChatGPT/Gemini/Claude referrals. **[S]**
4. Our own data overrides every study in these files once it exists.

## What this method is not

- Not a guarantee. Nothing here promises a position.
- Not a substitute for having something to say. Every documented quality criterion Google publishes points at original information and first-hand experience, which is the one thing automation cannot supply.
